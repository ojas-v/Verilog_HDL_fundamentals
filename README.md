# Comprehensive Verilog HDL & FPGA Design Log

This repository contains the complete source code, testbenches, and simulation files from my comprehensive study of Verilog HDL. It serves as a structured log of my progression from basic digital logic to complex state machines and memory design.

## 🛠️ Tools & Technologies
* **Language:** Verilog HDL (IEEE 1364)
* **Simulation & Synthesis:** Intel Quartus Prime (18.1) / ModelSim
* **Concepts:** RTL Design, Combinational/Sequential Logic, FSMs, Memory Modeling, Testbench Verification

## 📂 Repository Structure

The repository is organized progressively, covering the following core concepts:

* **`Section 3 - Data Types and Operators/`**: Fundamentals of Verilog syntax, nets, registers, and bitwise/logical operations.
* **`Section 4 - Modules and Testbench/`**: Establishing hierarchy, module instantiation, and writing robust verification testbenches.
* **`Section 5 - Verilog Design Styles/`**: Gate-level, dataflow, and behavioral modeling techniques.
* **`Section 6 - Verilog Structural Designs/`**: Building complex hardware from basic primitives.
* **`Section 7 - Verilog Combinational Design/`**: Multiplexers, decoders, encoders, and ALUs.
* **`Section 8 - Verilog Sequential Design/`**: Flip-flops, latches, counters, and shift registers.
* **`Section 9 - Verilog Functions and Tasks/`**: Reusable code blocks and procedural abstractions.
* **`Section 10 - Verilog Memory Design/`**: Modeling ROM, RAM, and register files.
* **`Section 11 - Verilog State Machines/`**: Mealy and Moore Finite State Machine (FSM) design and implementation.
* **`Section 12 - Verilog Design Examples/`**: Integration of the above concepts into complete, functional hardware designs.
